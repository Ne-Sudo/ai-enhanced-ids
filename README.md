# Final Year IDS

---- Project Overview ----
An AI enhanced Intrusion Detection System that is capable of identifying and responding to malicious network traffic in real time.

My system combines a baseline rule-based firewall with an ML-based Intrusion detection system (IDS) which allows for performance comparisons between both approaches.

This project was developed as part of the Final Year project for the BSc Computer Science (Network Computing) module at Brunel University

---- Technologies Used ----
Language: Python
Networking Tools: Scapy, Wireshark
ML: scikit-learn, NumPy, Pandas
Simulation & Testing: Mininet, Generated traffic
Version Control: Git & GitHub

---- Data Sources ----
All training data came from publicly available and anonymised datasets which include the CICIDS-2017 and UNSW-NB15. Any additional traffic was generated synthetically in a controlled environment.

---- Evaluation Metrics ----
Detection latency, CPU and Memory Usage, False Positive Rate (FPR), F1-Score
